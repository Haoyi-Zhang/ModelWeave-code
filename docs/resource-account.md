# Resource account

The recorded historical campaign used one worker, 22.483218395 CPU seconds,
22.498455762 wall seconds, 110,616 KiB peak RSS, and a maximum recorded case time
of 0.049032564 seconds. The associated integrated clean run used 50.36963 measured
child CPU seconds and 44.001889259 wall seconds. Those fields come from one saved
run and are not stitched together from interrupted runs.

The two final validation runs have their own telemetry in
`results/final-validation/run-1-clean.json` and `run-2-clean.json`. Runtime
variation is expected; scientific records, not timing fields, are the equality
criterion. Early exploratory resource use cannot be reconstructed completely and
is not included in these numbers.
